# Sicherheit / Security

Sicherheitsluecken bitte NICHT als oeffentliches Issue melden, sondern
vertraulich ueber GitHub "Security" -> "Report a vulnerability" (oder per
Nachricht an den Betreiber dieses Repositories).
Please do not open a public issue for security problems; use GitHub's
"Report a vulnerability" (Security tab) instead.

Unterstuetzt wird jeweils die neueste Version. / Only the latest release
is supported.
